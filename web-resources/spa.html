Что такое Nexus?

Nexus — это продвинутый Telegram userbot с расширенными возможностями безопасности и современными функциями.

🔒

Безопасность

  • Встроенная защита API
  • Кэширование сущностей
  • Автоматическое резервное копирование
⚡

Производительность

  • Поддержка последнего Telegram Layer
  • Быстрое исправление багов
  • Оптимизированная работа
📦

Модули

  • Богатая библиотека модулей
  • Совместимость с FTG, GeekTG, Hikka
  • Простое создание модулей

📦 Создание модулей

Базовая структура

from .. import loader, utils
from telethon.tl.types import Message

@loader.tds
class MyModuleMod(loader.Module):
    """Описание модуля"""
    
    strings = {"name": "MyModule"}
    
    @loader.command()
    async def mycmd(self, message: Message):
        """Описание команды"""
        await utils.answer(message, "Hello from Nexus!")
