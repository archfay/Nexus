📖 Документация Nexus

Полное руководство по использованию и разработке для Nexus Userbot

Что такое Nexus?

Nexus — это продвинутый Telegram userbot с расширенными возможностями безопасности и современными функциями. Он позволяет автоматизировать действия в Telegram, добавлять кастомные команды и расширять функциональность мессенджера.

🎯 Первый запуск

Получение API credentials

  1. Перейдите на my.telegram.org/apps
  2. Войдите с помощью номера телефона
  3. Создайте новое приложение
  4. Скопируйте api_id и api_hash

Настройка

При первом запуске Nexus попросит:

  • API ID - числовой идентификатор
  • API Hash - строка из 32 символов
  • Номер телефона - в международном формате
  • Код подтверждения - из Telegram
  • 2FA пароль - если включен

Веб-интерфейс

После успешной авторизации откройте браузер:

http://localhost:8080

🔧 Установка

Системные требования

  • Python: 3.9 - 3.13
  • ОС: Linux, macOS, Windows (WSL)
  • RAM: минимум 512 MB
  • Диск: минимум 100 MB

Быстрая установка

apt update && apt install git python3 -y && \
git clone https://github.com/archfay/Nexus && \
cd Nexus && \
pip install -r requirements.txt && \
python3 -m nexus

Пошаговая установка

# 1. Клонировать репозиторий
git clone https://github.com/archfay/Nexus
cd Nexus

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Запустить Nexus
python3 -m nexus

📦 Создание модулей

Базовая структура

from .. import loader, utils
from herokutl.tl.types import Message

@loader.tds
class MyModuleMod(loader.Module):
    """Описание модуля"""
    
    strings = {"name": "MyModule"}
    
    @loader.command()
    async def mycmd(self, message: Message):
        """Описание команды"""
        await utils.answer(message, "Hello from Nexus!")

Декораторы

  • @loader.tds — регистрирует класс как модуль
  • @loader.command() — регистрирует команду
  • @loader.watcher() — создаёт обработчик событий
  • @loader.loop() — создаёт периодическую задачу

from .. import loader, utils
from telethon.tl.types import Message
import logging

logger = logging.getLogger(__name__)

@loader.tds
class ExampleMod(loader.Module):
    """Пример модуля с полной структурой"""
    
    strings = {
        "name": "Example",
        "loading": "⏳ Загрузка...",
        "done": "✅ Готово!"
    }
    
    strings_ru = {
        "loading": "⏳ Загрузка...",
        "done": "✅ Готово!"
    }
    
    def __init__(self):
        self.config = loader.ModuleConfig(
            loader.ConfigValue(
                "auto_reply",
                True,
                "Автоответ",
                validator=loader.validators.Boolean()
            ),
            loader.ConfigValue(
                "delay",
                5,
                "Задержка (сек)",
                validator=loader.validators.Integer(minimum=1)
            )
        )
    
    async def client_ready(self, client, db):
        """Вызывается при запуске"""
        self.client = client
        self.db = db
        logger.info("Module loaded")
    
    @loader.command()
    async def example(self, message: Message):
        """Пример команды"""
        await utils.answer(message, self.strings["done"])
    
    @loader.watcher()
    async def watcher(self, message: Message):
        """Обработчик всех сообщений"""
        if "trigger" in message.text.lower():
            await message.reply("Обнаружен триггер!")

Обязательные элементы

  • Имя класса должно заканчиваться на Mod
  • Docstring с описанием модуля

Использование

@loader.command()
async def mycmd(self, message: Message):
    api_key = self.config["api_key"]
    timeout = self.config["timeout"]
    
    if not self.config["enabled"]:
        return
    
    await utils.answer(message, f"Timeout: {timeout}")

Валидаторы

  • String() - строка
  • Integer(minimum, maximum) - целое число
  • Float(minimum, maximum) - дробное число
  • Boolean() - да/нет
  • Choice([...]) - выбор из списка
  • Series() - список значений

Модуль с БД

from .. import loader, utils

@loader.tds
class NotesMod(loader.Module):
    """Заметки"""
    
    strings = {"name": "Notes"}
    
    @loader.command()
    async def addnote(self, message):
        """<имя> <текст> - Добавить заметку"""
        args = utils.get_args_raw(message).split(maxsplit=1)
        if len(args) < 2:
            await utils.answer(message, "❌ Укажите имя и текст")
            return
        
        name, text = args
        notes = self.db.get("Notes", "notes", {})
        notes[name] = text
        self.db.set("Notes", "notes", notes)
        await utils.answer(message, f"✅ Заметка '{name}' сохранена")
    
    @loader.command()
    async def note(self, message):
        """<имя> - Показать заметку"""
        name = utils.get_args_raw(message)
        notes = self.db.get("Notes", "notes", {})
        
        if name in notes:
            await utils.answer(message, notes[name])
        else:
            await utils.answer(message, "❌ Заметка не найдена")

🔒 Безопасность

⚠️ Важно!

  • Не используйте eval() с пользовательским вводом
  • Не храните токены в открытом виде
  • Проверяйте права доступа
  • Используйте try-except

Проверка прав

@loader.command()
async def admin_cmd(self, message):
    me = await self.client.get_me()
    if message.sender_id != me.id:
        return
    
    await utils.answer(message, "✅ Выполнено")

Безопасное хранение

@loader.command()
async def settoken(self, message):
    token = utils.get_args_raw(message)
    self.db.set("MyModule", "token", token)
    await message.delete()
    await self.client.send_message(message.chat_id, "✅ Токен сохранен")

❓ FAQ

Как загрузить модуль?

Используйте .loadmod имя_файла или .dlmod URL

Где хранятся модули?

В папке loaded_modules/

Как обновить Nexus?

Команда .update или git pull && pip install -r requirements.txt

Можно ли использовать внешние библиотеки?

Да, установите через pip install и импортируйте в модуле

🚨 Важное предупреждение

Установка модулей от непроверенных разработчиков может привести к повреждению вашего аккаунта. Всегда проверяйте код перед установкой!
