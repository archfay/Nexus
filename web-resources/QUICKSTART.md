# 🌐 Nexus Website - Краткая инструкция

## ✅ Что создано

Полноценный веб-сайт для Nexus с:
- 🔐 Авторизацией (вход по номеру + первая регистрация)
- 📖 Документацией (руководства по созданию модулей)
- 🎛️ Панелью управления (статистика, модули, настройки)

## 📁 Все файлы в папке `nexus-website/`

```
nexus-website/
├── index.html              # Главная с авторизацией
├── pages/
│   ├── docs.html          # Документация
│   └── dashboard.html     # Панель управления
├── static/
│   ├── css/               # Стили
│   └── js/                # JavaScript
├── README.md              # Полная документация
├── SETUP.md               # Инструкция по настройке
└── integration_example.py # Пример интеграции
```

## 🚀 Как использовать

### 1. Файлы уже в проекте
Папка `nexus-website/` находится в `/home/donotweb/Рабочий стол/Nexus/`

### 2. Интегрируйте в Nexus
Используйте `integration_example.py` как шаблон для добавления веб-сервера

### 3. Запустите
```bash
python3 -m nexus
```

Сайт будет доступен: `http://127.0.0.1:8080`

## 🎯 Основные страницы

- `/` - Авторизация (7 шагов: выбор метода → номер → код → 2FA)
- `/docs` - Документация (введение, создание модулей, API)
- `/dashboard` - Панель (статистика, модули, настройки)

## 🔧 Что нужно сделать

1. **Добавить веб-сервер** - используйте `integration_example.py`
2. **Реализовать API** - endpoints для авторизации, модулей, настроек
3. **Настроить безопасность** - JWT токены, CORS, валидация

## 📡 API Endpoints (нужно реализовать)

### Авторизация
- `POST /api/auth/send_code` - отправить код
- `POST /api/auth/verify_code` - проверить код
- `POST /api/auth/verify_2fa` - проверить 2FA
- `GET /api/auth/status` - статус

### Панель
- `GET /api/dashboard/stats` - статистика
- `POST /api/bot/restart` - перезагрузка
- `POST /api/modules/load` - загрузить модуль
- `POST /api/settings/save` - сохранить настройки
